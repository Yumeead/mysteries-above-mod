# Більші іконки здібностей

Усі готові іконки тепер відображаються більшими. PNG 32×32 використовуються наявним рендерером без перегенерації зображень.

| Місце | Було | Стало |
|---|---|---|
| Колесо, зокрема картка перемикання | 16×16 | 24×24 |
| Книга: бібліотека, клавіші, групи | 15×15 | 24×24 |
| Вибрана здібність у книзі | 15×15 | 32×32 |
| Обидва HUD | 16×16 | 24×24 |

[Порівняння до/після](comparison.png). Попередні огляди в каталогах окремих Pathways збережені як історія первинної перевірки.

Рядки книги збільшені до 28 пікселів; назви й позначки відсунуті від іконок та вирівняні по центру. Вибране зображення 32×32 розташоване поруч із назвою, Послідовністю й типом здібності. У вузькому вікні видно менше рядків; решта доступна прокручуванням.

Картки всіх трьох оформлень колеса збільшені до 30×30. Для 9–12 здібностей радіус підлаштовано так, щоб картки при наведенні не перетинались, а вартості залишались видимими у вікні 854×480 з GUI 2. Колірні позначки, вибір, відкат і картка перемикання використовують нові межі. Нижній HUD отримав комірку 28×28 зі скоригованими відступами для обох рук.

## Перевірка

`./gradlew.bat :core:test --tests me.vangoo.domain.hud.BottomPanelTest :mod:test --tests me.vangoo.mysteries.client.render.BookArtTest --tests me.vangoo.mysteries.client.render.WheelLayoutTest`

28 тестів пройшли. Вони включають розміщення HUD для обох рук і вузьких вікон, відсутність перетинів збільшених карток, видимість вартостей та покриття всіх PNG.

Ігрові перевірки запускаються окремо: `./gradlew.bat :mod:runClientGameTest -Ponly=Icons` та `./gradlew.bat :mod:runClientGameTest -Ponly=Wheel`.

17.11.2026 обидві ігрові перевірки завершилися успішно. `Icons` пройшов усі 106 готових іконок у колесі та книзі, додатково показав обидва HUD, три оформлення колеса, клавіші й групи. `Wheel` перевірив відкриття, закріплення, рух гравця, вибір здібності та її режиму після зміни геометрії карток. Знімки зроблено в Minecraft 26.2, OpenGL, GUI 2, 854×480.

GUI 3+ та Vulkan цим запуском не перевірялись.
