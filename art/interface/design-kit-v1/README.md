Це базові тони, не остаточні палітри сердець чи трубок. Поглинання лишається золотистим, отруєння — зеленим, висихання — темним зі світлим ребром, заморожування — крижаним; усі їхні форми й півтони будуть предметом ескізів HUD.

## Панель 9-slice

- Джерело **16×16 GUI px**, border **4** з усіх боків; мінімум **16×16**, текстові панелі — з відступом щонайменше **8 px**.
- Зовнішні кути зрізані на 2 px. Контур — 1 px; золотий кант — 1 px; усередині темна фаска й один стриманий відблиск. Кути не масштабуються.
- Центральний матеріал — `#14191F` приблизно 96%; tooltip — `#0E1318` приблизно 98%. Немає фонових рун, шуму, повторюваних візерунків чи великого glow.
- Статичний зразок: [draft-panel-16x16.png](draft-panel-16x16.png), [GUI metadata](draft-panel-16x16.png.mcmeta). Вони лежать лише в матеріалах дизайну й не підключені до гри.
- Ванільні темні назви контейнерів на етапі 2 потребують світлішої локальної вставки або окремого погодження світлого тексту. Кіт не приховує цю межу ресурсного оформлення.

## Слот, кнопка, підказка, роздільник

| Компонент | Пропозиція |
|---|---|
| Слот контейнера | Зразок **18×18**, всередині **16×16** для незміненого предмета. Кант займає лише зовнішній периметр. Порожній слот не зникає на темному тлі |
| Вибраний слот | Акцент шляху на периметрі плюс два світлі кутові знаки; відрізняється формою, а не тільки кольором. Для хотбара зберігається його окрема ванільна рамка **24×23**; кіт не зменшує її до 18×18 |
| Хотбар / друга рука | Матеріал слота спільний, але ванільні загальний розмір, крок і координати предметів зберігаються. Повну композицію покаже наступний етап |
| Кнопка | Типова висота **20 px**, текст без зміщення під час натискання. Шість станів: спокійна, наведення, фокус, обрана, натиснута, недоступна |
| Наведення / фокус / вибір | Наведення: світліший край. Фокус клавіатури: світлі кутові риски. Вибір: акцентна смужка й галочка. Ці стани можуть поєднуватися |
| Недоступна дія | Приглушена нейтральна рамка, читабельний сірий текст; без відблиску. Стан не замінює пояснення причини |
| Tooltip | Та сама рамка, центр непрозоріший; відступ 8 px, назва зверху, опис нижче. Кольори рідкості, атрибутів і custom tooltip style предметів зберігаються |
| Роздільник | Лінія 1 px приглушеного золота з короткою світлішою серединою. Без орнаменту, що змагається з флаконом |
| Повзунок | Темна доріжка, коротке акцентне заповнення, золотиста ручка, окремий focus; розмір клікабельної області не зменшується |
| Прокрутка | Вузька темна доріжка, ручка з золотим ребром; видима й без наведення. Остаточні розміри залежать від ванільного екрана |

Зразки задають матеріали. Вони не дозволяють змінювати hitboxes, перетягування предметів, порядок слотів чи розташування іншого мода. Глобальні ванільні `widget/*` поки не перевизначаються, бо це зачепить відкладені меню.

## Акцент шляху

1. **Одне наявне джерело:** `PathwayBranding.liquidOf(pathwayId)`. Не кольори chat-тексту `textOf` і не повторна таблиця в HUD.
2. Для тонких інтерфейсних деталей — похідна через наявне `GrimoireSkin.readableAccent`: підняття надто темних значень до мінімальної яскравості. Зразки всіх 22 шляхів отримані з поточного коду, а не підібрані окремо.
3. Один запасний акцент — **старе золото `#B99A61`** для відсутнього/невідомого шляху або недоступного стилю. Невідомий шлях не видається за один із відомих.
4. Застосування: край вибраного слота, заповнення XP, тонка лінія чи позначка вибраної картки. На звичайних панелях лишається золота рамка. Основний текст — світлий нейтральний.
5. Не фарбувати акцентом здоров'я, їжу, повітря, броню, боссбар, чужі server-тексти чи весь фон панелі. Рідина затвердженого флакона має свій незмінний художній малюнок.

Це пропозиція єдиного правила для майбутнього узгодження UiTheme, книги, кола й HUD. У поточному коді воно ще не застосоване.

## Шрифт і стани

**Залишаємо ванільний шрифт Minecraft.** У зразках використані справжні bitmap glyphs із 26.2, а не схожий системний шрифт. Підтверджено `і ї є ґ І Ї Є Ґ`, цифри, звичайні знаки та українські рядки. Дрібний текст малюється в рідному розмірі, стандартний крок рядків — від 10 px; потрібні більші заголовки мають лише цілий множник.

Спокійний стан приглушує декор, не значення. Критичний стан додає знак і чіткий текст/силует, зберігаючи читабельність заповненого та порожнього ресурсу. Фокус клавіатури незалежний від небезпеки. Нових порогів HP/голоду/духовності цим кітом не встановлено; вони узгоджуються з ескізами та наявними правилами. Режими reduced motion і явне вимикання елемента гравцем мають зберігатися.

## Спільність наших екранів

На B, у колі, книзі й редакторі використовуються ті самі золото, контур, текст, focus, selected та tooltip. Книга може зберегти характерну обкладинку; коло — форму; їхні компоненти належать спільному кіту. У [фрагментах](03-shared-surfaces-x3.png) показано також майбутній пункт **«Стиль інтерфейсу: ванільний / мод»**, типовий — «мод». Це лише зразок, config не змінено.

## Що перевірено та що далі

- Збережено **15 PNG**: огляд ×2/×4, 9-slice, приклади застосування, всі акценти, вісім варіантів тла/масштабу та критичний стан.
- На твоєму скріні використано оригінал **986×328** без зміни масштабу. Світле/темне/сніжне тло — фрагменти **986×280** з попередніх справжніх кадрів гри, без масштабування фону. Це нові композиційні зразки, не знімки працюючої теми.
- Сама тестова панель — **144×88 GUI px**: **288×176** при Scale 2, **432×264** при Scale 3. Решта ванільного HUD на наданому crop не має встановленого масштабу; він не є вимірювальним еталоном.
- Перевірки: [verification.json](verification.json); походження картинок і glyphs: [provenance.json](provenance.json). Окрема контрольна сума всіх файлів `mod/src` та `core/src` підтверджує, що вони залишилися незмінними.
- Auto, поведінка у вузьких вікнах, шульга, анімація та сумісність ще потребують реалізації й перевірки в грі. Галерея компонентів цього не доводить.

**Наступний крок тільки після підтвердження цього кіту:** ескізи HUD А/Б/В, повний набір станів, E/скриня, B/перетягування на погоджених матеріалах. Аудит і цей кіт не дають дозволу змінювати код або починати етап 1.
