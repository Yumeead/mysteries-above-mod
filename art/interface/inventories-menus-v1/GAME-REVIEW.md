# Золото й однакові комірки: ігровий огляд

**[Відкрити реальні кадри](game-review.html)**. Minecraft Java **26.2**, вікно **1920×1080**, мова **українська**, фактичні GUI Scale **2 / 3**. Усі PNG отримані через рідний `Screenshot.grab`, скопійовані побайтово, без ретуші, домальовування або накладання макета. [Походження, класи екранів, розміри, SHA-256](in-game/captures.json).

Це ізольований ігровий перегляд для погодження. Запущено наявну збірку мода, копію тестового світу й оглядовий ресурспак. Тимчасовий клієнтський помічник з `live-preview` автоматично відкриває штатні екрани та знімає кадри. Робочі `core/src`, `mod/src`, користувацькі світи й налаштування не змінені. Інтеграція оформлення в основний мод і перемикач стилю залишаються окремим етапом після затвердження.

Остання правка — лічильник книги: темне поле підняте й звужене навколо штатного тексту. [Перша сторінка ×4](in-game/details/pagination-page1-from-gs3-x4.png), [друга сторінка ×4](in-game/details/pagination-page2-from-gs3-x4.png) — збільшені фрагменти нових ігрових кадрів; оригінали в таблиці нижче.

## Зміни

1. **Панелі:** рамка 2 GUI px із трьох затверджених тонів `#DFC28B / #B99A61 / #65533A`. Золото зверху й ліворуч світліше, знизу й праворуч середнє, зовнішній край темний. Усередині бліде золото `#DCC58D` із розрідженим дізерингом RGB ±1. Темний ванільний текст `#404040` лишається незмінним; розрахунковий контраст із базою — **6,13:1**.
2. **Усі слоти:** одна бронзово-золота база `#BA985B`, включно з хотбаром, другою рукою, бронею, крафтом, результатом і рецептами. Внутрішня тінь `#896337`, світла внутрішня кромка `#D1B071`, однаковий темний контур `#70502D` завтовшки 1 px з усіх чотирьох боків. Горизонтальні межі більше не виділені широким світлим ребром. Золоті предмети використовують оригінальний рендер і свій контур; фон слота не затемнюється окремо під ними.
3. **Одна палітра:** панелі, кнопки, підказка, вкладки, значки та стрілки беруть метал із одного кіту `build-review.py`. В оглядовому паку збережені оригінальні фізичні розміри PNG, UV, координати й крок слотів; [маніфест текстур](live-preview/pack-manifest.json).
4. **Пауза:** заголовок отримав темне заповнення й таку саму золоту оправу, як кнопки. Він розміщений на 8 GUI px вище першої кнопки. Кнопки зберегли ванільні ширини 204 / 98 / 20 px і свої дії. Значки жука, чату, друзів та повідомлення перефарбовані у золото й темні тони зі збереженням силуетів. Штучний «+» замінено справжньою ванільною іконкою друзів у палітрі кіту.
5. **Фокус:** верхнє світле ребро в попередньому макеті першої кнопки показувало наведення. Тепер звичайний стан і клавіатурний фокус зняті окремо. Для будь-якої кнопки діють ті самі спрайти станів; клавіатурний фокус додатково отримує золоті кути. Винятку для «Назад до гри» немає.
6. **Рецепти:** вкладки приєднані до теплої золотої панелі; вибрана виступає й має відкритий стик із панеллю, інші трохи втоплені. Сітка рецептів і крафт використовують той самий матеріал комірки. Стрілки 2×2 та верстака тепер будуються одразу на сітці 18×15 / 22×15, без стискання й зміщеної тіні: симетричний силует, рівний контур 1 px, золота середина. Лупа має круглу лінзу й пряму ручку під 45° у палітрі кіту. Стрілки сторінок 12×17 перемальовані тим самим компонентом, ліва точно дзеркальна правій; наведення освітлює середину зі збереженням темного контуру. Відкриття книги й перехід на другу сторінку виконуються штатними подіями гри.
7. **Повзунки налаштувань:** справжній `SoundOptionsScreen` показує темну середину, золоту рамку 2 px та золотий бігунок 8×20. Окремо зняті звичайний стан і наведення після перетягування; нативні click/drag/release перевірені зміною загальної гучності з 72% до приблизно 62%. Змінюються тільки налаштування тимчасової копії. У попередній галереї справжнього екрана налаштувань не було; тепер він є на обох масштабах.
8. **Лічильник сторінок:** спільна рамка кіту тепер розташована на `(54,137)` із розміром `38×17` від початку книги. Текст залишається на ванільному `y=141`, центр `x=73`; кнопки залишаються на `(38,137)` і `(93,137)`. Оглядовий експортер враховує UV `(1,1)` фонової текстури. Цифри разом із тінню вміщуються всередині; між рамкою та малюнком стрілок є 5 GUI px ліворуч і 2 GUI px праворуч. Для першої й другої сторінок на Scale 2 / 3 перевірені нативні метрики та видимі білі пікселі цифр. Попередня рамка `(54,140,42,18)` цієї перевірки не проходить.

У підказці збережені рідність, текст і штатні кольори предмета; декоративної лінії під назвою немає. Довільні додаткові кольори у значках паузи прибрані; окремі майбутні сигнали небезпеки не підміняються кольором шляху.

## Межі перевірки

Для кадрів відкриті справжні `InventoryScreen`, `ContainerScreen`, `CraftingScreen`, `PauseScreen` і `SoundOptionsScreen`. Предмети та модель гравця малює Minecraft; скриня й верстак відкриваються через взаємодію зі справжніми блоками в копії світу. Пакет огляду перенаправляє спільні кнопки, повзунки й підказки лише на ванільних екранах цього етапу; титульний екран зберігає свої спрайти.

Не перевірені всі інші контейнери, сторонні доповнення рецептів, усі сценарії введення/нарації та майбутній перемикач стилю. Тимчасовий помічник не включений у робочу збірку. Оглядовий ресурспак не вмикається у вашій звичайній грі.

[Перевірка кадрів, текстур і галереї](in-game/verification.json): 18 PNG побайтово збігаються з виходом Minecraft; фізичні розміри вихідних текстур збережені; для 1095 розпізнаних слотів перевірені спільна база та однакові межі. Галерея завантажує всі 18 кадрів. Перевірені перетягування повзунка та перехід сторінки. [Перевірка макетів](verification.json) також підтверджує незмінність 1786 попередніх відстежуваних файлів і симетрію нових стрілок.

## Відтворення огляду

З кореня checkout, використовуючи наявні JDK 25, Python/Pillow та локальний JAR 26.2:

```powershell
.\gradlew.bat :mod:writeMenuReviewLaunch -I art/interface/inventories-menus-v1/live-preview/launch.init.gradle --console=plain
python art/interface/inventories-menus-v1/live-preview/export-pack.py
python art/interface/inventories-menus-v1/live-preview/run-review.py
python art/interface/inventories-menus-v1/live-preview/capture.py
python art/interface/inventories-menus-v1/live-preview/verify.py
```

Запуск створює окрему папку в системному Temp і копію тестового світу. `session.json` зберігає її шлях; запит `stop` у її `request.txt` штатно закриває клієнт. Для перевірки походження потрібні вихідні PNG у цій тимчасовій папці.
