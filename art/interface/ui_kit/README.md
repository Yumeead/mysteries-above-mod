# Затверджений кіт інтерфейсу — етапи 1–2

`kit.py` — єдині піксельні примітиви: золота рамка 2 px, світле поле, бронзовий слот, кнопки та стани, повзунок, прокрутка, стрілки й лупа. Кіт не залежить від шрифту, гри або макетів. Галерея огляду використовує ці ж примітиви.

`generate.py` випікає кіт у клієнтські ресурси мода. Потрібні Python із Pillow та локальний оригінальний JAR Minecraft 26.2. За потреби шлях передається через `--minecraft-jar`.

```powershell
python art/interface/ui_kit/generate.py
python art/interface/ui_kit/generate.py --check
```

Генератор створює 27 PNG і відповідні метадані. `manifest.json` містить розміри, SHA-256 та всі 46 / 90 розпізнаних слотів оригінальних атласів. Усі файли належать `mysteries_above:`; глобальних перевизначень `minecraft:` немає. Фони E і скрині зберігають ванільні 256×256, UV та слот другої руки `(76,61)`. Вони побайтово збігаються із затвердженим ігровим оглядом.

Робочий етап 2 оформлює штатний `InventoryScreen` та `ContainerScreen` на 3 рядки. Ванільні скриня, ендер-скриня й бочка використовують один екран і фон 9×3, тому це оформлення спільне для них. Власні підкласи екранів модів не перехоплюються. Решта контейнерів, книга рецептів, підказки, пауза й налаштування очікують наступних етапів; наявність примітиву в кіті не вмикає його автоматично.

Наявний пункт **B → шестерня → Вигляд → Стиль інтерфейсу → Ванільний / Мод** керує HUD та цими контейнерами. Підміна Identifier умовна й миттєва; окремий ресурспак і перезавантаження ресурсів не потрібні. Ванільний режим повертає оригінальні ресурси з поточного набору ресурспаків, включно зі сторонніми.

Після етапу 2 потрібна перевірка користувачем у грі перед продовженням етапів 3–5.
