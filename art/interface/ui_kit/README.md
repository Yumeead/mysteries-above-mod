# Золотий інтерфейс — етапи 1–5

`kit.py` — спільні піксельні примітиви: рамка 2 px у трьох золотих тонах, тепле світле поле, бронзовий слот, кнопки та стани, повзунок, прокрутка, стрілки й лупа. Усі звичайні слоти, включно з хотбаром усередині інвентарів і крафтом, використовують один матеріал. Кольорових декоративних підкреслень немає. Шрифт і кольори рідкості предметів залишаються ванільними.

Генератор випікає 248 PNG та метадані з оригінального клієнтського JAR 26.2. Потрібні Python із Pillow та локальний JAR; інший шлях можна передати через `--minecraft-jar`.

```powershell
python art/interface/ui_kit/generate.py
python art/interface/ui_kit/generate.py --check
python art/interface/ui_kit/verify-kit.py
```

`manifest.json` містить розміри, SHA-256 та координати розпізнаних слотів. `interface-palette.json` передає ту саму палітру фокусу й виділенню списків у клієнтському коді. Розміри PNG, UV, координати й області натискання збережені. Окремо перевіряються однакові межі клітинок, вкладки творчого інвентарю, GUI Scale 1–4 та відступи лічильника сторінок книги рецептів. Друга рука в E лишається у ванільному `(76,61)`.

Підміна `Identifier` умовна, лише на штатних екранах Minecraft. Ресурси належать `mysteries_above:`; глобальних перевизначень `assets/minecraft` немає. Власні класи екранів модів та їхні підкласи не перехоплюються, як і власні класи віджетів модів на штатних екранах. Генератор не змінює клік-зони, меню, рецепти чи серверну логіку.

Стиль перемикається одразу через **B → шестерня → Вигляд → Стиль інтерфейсу → Ванільний / Мод**. Ванільний режим повертає оригінальні ідентифікатори, звичайні заголовки й виділення, включно з ресурсами активних сторонніх паків. Перезавантаження ресурсів не потрібне. Титульний екран і оформлення B не змінювалися.

## Охоплення

| Етап | Робоче оформлення |
|---|---|
| 1 | Кіт, генератор і реєстр ресурсів |
| 2 | E, броня, друга рука, модель гравця, 2×2, ефекти й одинарна скриня |
| 3 | Подвійна й ендер-скриня, бочка, шалкер, верстак, три печі, ковадло, зачарування, ковальський стіл, точило, ткацький верстат, картограф, камнеріз, зілляварка, маяк, воронка, роздавач, викидач, торгівля, кінь і лама; підказки, підсвітка й книга рецептів |
| 4 | Пауза; штатні налаштування, список, кнопки, перемикачі, повзунки, текстові поля, вкладки, чекбокси й прокрутка |
| 5 | Творчий інвентар із вкладками, пошуком і прокруткою; автоматичний майструвач та інвентар наутилуса 26.2 |

Темні контейнерні підписи лишаються нативними, тому панелі світлі. Підказки мають темне напівпрозоре тло та золоту рамку. У паузі заголовок має темну заливку й наближений до кнопок. Кутові дужки позначають фокус клавіатури; наведення й утримання миші використовують свої стани. Маленькі іконки паузи виконані золотом кіту.

## Ігрова перевірка

[Галерея локальних кадрів](in-game/stages-3-5/index.html) показує оригінальні PNG 1920×1080 з Minecraft 26.2; натискання відкриває повний розмір. Фільтри дозволяють порівнювати стиль і GUI Scale. Файли кадрів локальні, до JAR не входять. [Протокол перевірки](screens-verification.json) містить класи екранів, масштаб, SHA-256 і перевірену геометрію.

Перевірено 118 кадрів: основні екрани на Scale 2 / 3 в обох стилях, темне кам'яне приміщення на Scale 2 / 3 та компонування E, верстака, паузи, повзунків і творчого інвентарю на Scale 1 / 4. Є окремі кадри фокусу, натиснутого перемикача й перетягнутого повзунка. Ванільні лінії-роздільники налаштувань у режимі «Мод» прозорі.

Сеанс використовує копію тестового світу в `%TEMP%`, без оглядового ресурспака та без його підміни малювання. Для повторного запуску з матеріалів огляду:

```powershell
.\gradlew.bat :mod:classes :mod:clientClasses :mod:writeMenuReviewLaunch -I art/interface/inventories-menus-v1/live-preview/launch.init.gradle
python art/interface/inventories-menus-v1/live-preview/run-review.py --integration
python art/interface/ui_kit/check-screens.py
python art/interface/ui_kit/check-screens.py --screens pause settings settings-hover language creative creative-search creative-inventory
python art/interface/ui_kit/check-screens.py --screens inventory chest crafting furnace tooltip pause --scene cave --styles mod
```

Оглядовий запуск потребує наявного локального світу `mod/run-flask-review-20261018/saves/Flask Review`; це перевірка на робочому ПК, а не автономний CI. Скриня й контейнери блоків відкриваються через штатну взаємодію. Торгівля та інвентарі тварин використовують штатні екрани з підготовленими клієнтськими даними: це перевіряє малювання, а не серверну торгівлю чи приручення. Натискання вкладок і стрілки наступної сторінки, введення українського пошуку, прокрутка творчого інвентарю та перетягування повзунка перевіряються через нативні обробники вводу. Перемикач стилю також натискається у справжньому `HudSettingsScreen`.

`:mod:test` та `:mod:jar` проходять. Повний `:mod:build` у поточному робочому дереві зупиняється на сторонніх незакомічених `CreatureGameTests.kt:147–148` (`RED_BED`); зміни інтерфейсу цих файлів не торкаються. Старий [звіт етапу 2](STAGE-2.md) збережений як історичний.

JEI/REI/EMI не встановлені й не перевірені наживо. Збереження ванільної геометрії та виключення чужих класів зменшує ризик несумісності, але не замінює запуск із конкретним доповненням.
