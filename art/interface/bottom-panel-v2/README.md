Галерея дозволяє перемикати ці стани, чотири тла, GUI Scale 1–4, обидва півсерця, дві оправи, три шляхи, шульгу, другу руку, допоміжні елементи та режими без кулі. Збільшення ×4 формується з GUI-сітки, а не повторним збільшенням екранного ×3. Відкривати при масштабі браузера **100%**, горизонтальні зображення прокручувати.

У звичайному режимі Minecraft 1280×720 обмежує масштаб до 3; примусова парність Unicode може дати 4. Обидва випадки пояснені в аудиті.

## Рекомендований напрям для вибору

Тонка 40 px оправа стриманіша й краще лишає рідину головним акцентом. Рельєфна 44 px — варіант із чотирма скобами та нижнім знаком. Додані темний камінь із кількома регулярними тихими жилами, старе золото на вузькому канті та окреме скло. Рідина всередині **30×30, 1:1** для обох оправ.

Порожні серця й ніжки мають прозору середину та світле скляне ребро з темним зовнішнім краєм у початковій 9×9 масці. Темний край потрібен для снігу й неба; світле ребро — для печери. Повне серце містить рубінову рідину трьох тонів. Півсерце за висотою й ліва половина показані поруч; обидва мають повний силует посудини. Для швидкого звичного читання рекомендована ліва половина, але обидва варіанти відкриті для вибору. Галерея спочатку показує варіант за висотою, щоб відразу перевірити запитану нову форму.

Понад 20 HP рекомендовано зберегти ванільні ряди й прибрати їхню важку непрозору підкладку. Компактну смугу показано як альтернативу зі зміною верхнього ряду, а не як непомітну «сумісну» заміну.

Друга рука лишається в її ванільному місці й дзеркалиться для шульги; індикатор атаки займає інший бік. Куля зліва та здібність справа при цьому не перестрибують. Для вузького вікна куля пересувається вище зовнішнього слота, декор і брелок ховаються, права панель стає 60×44. Дробового масштабування немає.

У режимі «Стара смуга» велике ліве крило замінюється малою вставкою; у «Вимкнено» лишається низьке закінчення. Центральні предмети не зсуваються.

## Походження та межі

- Рідина й брелки: незмінні робочі PNG мода. Жоден генератор рідини не запускався. Нові форми, рамки й відблиски — окремий макет на integer Canvas.
- Базова палітра й мова панелей — кіт 01.1; додано камінь, рубін HP та три приглушені семантично незалежні кольори тестових смуг. XP — зелений за новою вимогою, незалежний від шляху.
- Для світла оправи використано останній тон наявної JSON-палітри шляху; для вибраної рамки — наявний readable accent. Гравіювання та нейтральні знаки відрізняють шляхи без кольору. Grayscale — тільки перевірочний перегляд.
- Шрифт: bitmap glyphs Minecraft 26.2 зі збереженого попереднього огляду; предмети та початкові 9×9 силуети — ресурси того самого локального JAR.
- Ваш попередній скрін — **обрізаний** файл 986×328 з минулого огляду. Використано вже наявне художньо очищене тло, створене раніше imagegen; його походження описане в [попередньому README](../hud-concepts-v1/README.md). Оригінал не ретушувався. Це накладання нової композиції на crop, не вимір масштабу старого кадру. Нового виклику imagegen на цьому етапі не було.
- Небо, печера й сніг — наявні кадри 1920×1080. Макети 1280×720 використовують те саме тло; зменшення фону не змінює GUI-сітку або текстуру рідини.
- Це **37 PNG** та локальний технічний перегляд, не реалізований HUD. Немає запуску нового HUD у Minecraft чи перевірки шейдерів. Механіка рідини, точний поточний стан її анімації, сумісність і конфлікт компактних HP зі збереженням ванільних рядів докладно зазначені в [аудиті](AUDIT.md).

Наступний етап — вибір оправи й півсерця, правки ескізів. Код можна змінювати лише після явного **«затверджую»** щодо реалізації.
