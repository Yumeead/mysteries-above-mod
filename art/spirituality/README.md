# Флакони духовності

**Актуальна речовина:** [точне перенесення кольорів і фактури з еталона v4](mockups/v7-liquid-reference/README.md),
[порівняння еталона з грою](mockups/v7-liquid-reference/compare.html).

Корок, обв'язки, гравіювання й палітри походять із погоджених ескізів `mockups/v4`.
Брелки повернуті до оригінального вигляду: 19 текстур відновлені без змін,
лише Темрява, Демонеса й Безодня мають локальні виправлення з оригінальних пікселів v4.
Один постійний вигляд на кожен із 22 шляхів, без змін за послідовністю.
Куля й коричневий корок спільні. Позаду кулі — необов'язкова кругла піксельна тінь;
за замовчуванням вимкнена. Калюж, підставки й відображень під колбою немає.

Відтворити PNG та JSON: `python art/spirituality/generate.py` (потрібен Pillow).
Скрипт перезаписує свої результати; ручні виправлення спершу збережіть окремо.
Він не перезаписує початковий аркуш. Для трьох проблемних прикрас `TAG_REPAIRS` у генераторі
повертає темні пікселі вихідного малюнка й закриває кілька точкових прогалин кольорами того самого оригіналу.
Окремих перемальованих силуетів немає; `mockups/v4` залишається незмінним еталоном.
Початковий аркуш: `mockups/v4/sources/native-atlas-110-states.png`.

## Ресурси

JSON: `mod/src/client/resources/assets/mysteries_above/hud/spirituality/`.
PNG: `mod/src/client/resources/assets/mysteries_above/textures/gui/sprites/spirituality/`.
Розмір кожного шару — 64×56 GUI пікселів; сама колба займає приблизно 48 пікселів заввишки.

- `frame`, `glass`, `mask` — спільні куля, корок, відблиски та двійкова маска порожнини.
- `backing` — спільна округла підкладка з трьома рівнями непрозорості 40%, 50%, 60%;
  тільки зовнішній перехід має дізеринг. Окремий перемикач «Підкладка флакона: Немає / М’яка тінь».
- `neck`, `tag`, `engraving` — окремі шари оздоблення шляху.
- `palette` — шість дискретних тонів рідини, від темного до світлого.
- `tones` — маска фактури з погодженого малюнка: індекси 0–5, а не додатковий градієнт.
- `particle`, `particleCount` — піксельна форма й кількість дрібних частинок.
- `flow`, `periodTicks` — характер і період їхнього руху.
- `tagSwing` — мала амплітуда етикетки; вона реагує на рух гравця.

Для всіх 22 шляхів речовину тепер задає `liquids`: чотири повноколірні `liquid_*.png`
з оригінальних малюнків. `palette`, `tones` і процедурні частинки використовуються резервним
рендером для описів без `liquids`. Для ручної зміни кольорів і фактури редагуйте саме `liquid_*.png`.
`python art/spirituality/generate.py --liquids-only` відтворює лише речовину й не чіпає брелків.

У WheelOfFortune, Visionary, Death, Darkness, Chained і BlackEmperor нижні 1–3 рядки локально
продовжені кольорами сусідньої речовини: прибрано залишки скла й чорного контуру.
Таблиця `LIQUID_BASE_ROWS` у генераторі зберігає ці виправлення для всіх чотирьох рівнів.
Кольорової риски праворуч на оправі більше немає.

Власний JSON із `pathway`, що збігається з ID шляху, не потребує змін рендера.
Без опису використовується `default.json`. F3+T перечитує ресурси.
Генератор містить типові параметри для погоджених 22 малюнків; готові JSON можна редагувати окремо.

## Рендер і число

Поверхня й фактура на намальованих рівнях відповідають оригіналу v4. Між чотирма станами
висота змінюється плавно; ненульовий запас лишає щонайменше один піксель. Поповнення
м'яко прискорюється та сповільнюється. Базові світло, гравіювання й фактура збережені у вихідному малюнку.
Поверх рідини рухаються дрібні бульбашки та світлові течії, обмежені її намальованими пікселями.
Режим зменшеного руху вимикає цей додатковий шар. Остання ненульова крапля не перекривається частинками.

Поточна й максимальна духовність малюються двома невеликими рядками **всередині скла**,
без зовнішнього підпису й чорної плашки. Обидва рядки світлі з тонким суцільним темним контуром.
Наявні режими «При зміні / Завжди / Ніколи»
діють і для флакона, і для смуги. У редакторі вимкнена духовність має тестовий флакон.

Чиста логіка рівня, частинок і згладжування міститься в `core/domain/hud`;
Minecraft-рендер і налаштування — лише в клієнтській частині `mod`.

## Перевірка в грі

Драйвер знімків: `MYSTERIES_WHEEL_SHOTS=spirituality`,
`MYSTERIES_SHOTS_WORLD=<назва копії світу>`, задача `:mod:runClient`.
Він змінює тестового гравця, тому використовуйте копію світу й окрему папку гри.
Перевіряє GUI Scale 2/3/4, три шляхи й п'ять рівнів, ліву руку, вузьке вікно,
налаштування, чат, інвентар, перетягування, скидання й збереження.

`MYSTERIES_WHEEL_SHOTS=flask-review` додатково знімає всі 22 шляхи разом через справжній
рендер флаконів і чисел: п'ять рівнів на небі, снігу й у темній печері при GUI Scale 2/3/4,
а також порівняння з необов'язковою тінню й збереження перемикача. Сценарій будує тестову стіну та кімнату;
запускати тільки в окремій папці гри з копією світу. Актуальний результат — `mockups/v7-liquid-reference/README.md`.
