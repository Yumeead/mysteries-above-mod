# Речовина з еталона v4 у грі

[Порівняння «еталон → кадр гри» для кожного з 22 шляхів](compare.html).

Речовина перенесена з оригінального аркуша `v4/01-all-22-pathways-x4.png` через його збережений атлас. Замість шести кольорів і процедурного затемнення використовується повний вихідний RGB-малюнок: світлові пасма, внутрішній об'єм, портали, зірки, насіння, іскри й фактура кожного шляху. На рівнях, намальованих в еталоні, кольори й розташування видимих пікселів речовини збігаються з ним.

## Перевірка збігу

1. Перевірено всі 157 696 пікселів 44 початкових комірок атласу: після компонування на фоні еталонного аркуша вони точно відповідають його зображенням на 33% і 100%.
2. Minecraft запущено з робочим рендером. На двох контрольних кадрах при GUI Scale 4 показані всі 22 шляхи без чисел, щоб вони не перекривали речовину. Знімки не ретушовані.
3. `verify_liquids.py` порівняв **26 081 видимий логічний піксель речовини** з еталоном. Перевірено всі 16 пікселів екранного блока кожного такого пікселя: **417 296 пікселів знімків, 0 розбіжностей**, 44 пари «шлях / стан».

[Повний машинний результат перевірки](pixel-check.json). Повторити перевірку збережених кадрів:

```powershell
python art/spirituality/verify_liquids.py
```

Область порівняння — перенесена речовина у внутрішній масці колби. Пікселі, які закриті горлечком або брелком, враховані окремо й виключені з порівняння видимого шару. Контур, корок і прикраси не є частиною перевірки збігу речовини. На звичайному HUD числа відображаються, як раніше.

## Робочі малюнки

Для кожного шляху в `mod/src/client/resources/assets/mysteries_above/textures/gui/sprites/spirituality/<шлях>/`:

- `liquid_full.png` — повна речовина з еталона.
- `liquid_third.png` — речовина на 33%.
- `liquid_low.png` — малюнок v4 на 10%.
- `liquid_minimum.png` — малюнок v4 для мінімального запасу.

Це прозорі PNG 64×56 зі збереженими RGB-кольорами. Рендер не накладає поверх них загальне затінення, додаткові частинки, відблиски або гравіювання: потрібні деталі вже є в оригіналі. Порожнє скло й прикраси лишаються окремими шарами. Речовина відображається з повною насиченістю на світлому й темному тлі; її кольори не приглушуються налаштуванням прозорості панелей.

Чотири намальовані стани є орієнтирами. Між ними плавно змінюються висота й кольори; тест перевіряє монотонність підйому й останню ненульову краплю. Піксельний збіг із аркушем виміряний саме на двох наявних у ньому рівнях — 33% і 100%. Статична фактура походить із малюнка; анімація зміни запасу збережена.

Відтворити тільки речовину, зберігши ручні правки брелків та інших шарів:

```powershell
python art/spirituality/generate.py --liquids-only
```

Ця команда перезаписує `liquid_*.png` та їхні описи в JSON. Ручні правки самої речовини перед нею слід зберігати окремо. Звичайний запуск генератора без прапорця, як і раніше, відтворює також решту шарів.

- 157 наявних файлів ескізів і шарів залишилися побайтово незмінними, включно з усіма файлами v4, брелками, горлечками, гравіюванням і контуром.
