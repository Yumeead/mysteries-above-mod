# Ескіз 4 — усі 22 шляхи

**Один постійний вигляд флакона на весь шлях. Послідовність не змінює його оздоблення.**
Це рішення замінює щаблі оформлення з попередніх ескізів. Колба — варіант А без підставки.
Скляна куля й нейтральний коричневий корок спільні для всіх шляхів.
Після останнього перегляду прибрані всі плями, тіні й відображення під колбами.

Для кожного шляху є п'ять станів: 0%, 10%, 33%, 100%, 0,5%.
Загалом 110 зображень стану. Це рівні духовності, а не різні моделі флакона.

## Спільні правила

- Куля, кут огляду й корок не залежать ні від шляху, ні від послідовності.
- Відмінності: форма й матеріал етикетки, обв'язка, гравіювання, текстура й рух вмісту,
  колір рідини й світіння. Порожній флакон теж має бути впізнаваним.
- На 100% світлі відблиски та гравіювання лишаються поверх рідини.
- Верх над рідиною прозорий; скло читається завдяки краю, відблискам і задній стінці.
- Рівень у майбутньому рендері — за висотою внутрішньої кулі, мінімум один піксель при ненульовому запасі.
- Палітри спираються на `PathwayBranding`; наведені мотиви — пропозиція художнього оформлення.
- Для Дурня, Mother і Правосуддя підписи збережені відповідно до термінів користувача;
  внутрішні ID відповідають реєстру репозиторію.

## Читабельність

У розмірі 1:1 найперше губляться малі знаки на етикетках, окремі намистини й ланки.
Для малого масштабу спрощуємо ці внутрішні деталі, зберігаючи силует підвісу, обв'язку
та гравіювання. Рідина має 4–6 основних тонів; декоративні частинки не закривають поверхню.

## Перевірка й межі

Звірено всі 22 ID із репозиторієм, наявність 110 станів і 22 окремих карток,
однаковий фрагмент корка, точне збільшення ×4 та відмінність порожнього й мінімального рівня.
PNG — художні ескізи, не готовий набір покадрової анімації чи кінцеві шари рендера.
Опис руху окремо, в `ANIMATION.md`; гру для цього не запускали.
